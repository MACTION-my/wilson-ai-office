这个演示怎么接上真实的 AI

现在的动画由脚本模拟的事件驱动，自动化也是模拟的。换成真实 Agent 后，画面逻辑完全不用改：每个 ⚡ 自动化对应一个定时任务（Cloud Scheduler）或触发器，到时间就调用对应部门的 Agent，把事件写进 Firestore。

01每个部门一个 Agent

Sasa 拆任务、汇总、送审；Nana 接 Meta 广告后台，Kiki 接 WhatsApp Business，Mimi、Bobo、Lulu 负责内容、视频和设计，Wawa 盯订单和流程。

02Agent 运行时推送事件

每次思考、调用工具、交接、送审、批准，都发一条事件到前端。右侧「事件流」里的每一行就是一条事件。

03前端把事件变成动画

tool_call 让小宠坐下干活或去拍摄区，handoff 让它带着文件走到同事那里，approved 让 Wilson 盖章、全员庆祝。

// 接真实后端：把模拟脚本换成 WebSocket 推送的事件
const ws = new WebSocket("wss://your-backend/agents");
ws.onmessage = (e) => {
  const ev = JSON.parse(e.data);  // {"agent":"kiki","event":"tool_call","tool":"reply_whatsapp"}
  emit(ev.agent, ev.event, ev);   // 同一个 emit()，画面和看板自动更新
};
